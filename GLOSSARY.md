# TradeGear

A real-time algorithmic trading web application bridging MetaTrader 5 (MT5) with FastAPI backend, telemetry monitoring, strategy recommendations, automated risk management, and execution controls.

## Language

**TradeGear**:
The unified web application brand and interface for monitoring accounts, managing trades, and controlling MT5 bridge automation.
_Avoid_: Robot Trading Dashboard, MT5 Connection Dashboard

**Bridge Status**:
The live telemetry health state between the FastAPI backend and the MT5 Expert Advisor bridge.
_Avoid_: Ping status, EA connection state

**Kill Switch**:
An emergency system lockdown that immediately closes open positions and halts all new order executions until manually reset.
_Avoid_: Panic button, emergency stop

**Drawdown Guard**:
An automated risk control that tracks daily peak-to-trough equity loss and locks out trade execution once the predefined loss limit is hit.
_Avoid_: Loss limiter, daily cap

**AutoPilot**:
The operational mode where strategy signals are executed directly to MT5 without requiring trader manual confirmation.
_Avoid_: Full auto bot, automated trader

**Semi-Auto Approval**:
The operational mode where strategy signals are queued and require manual trader one-click approval before being sent to MT5.
_Avoid_: Manual signals, prompt trade

**Strategy Signal**:
A trade recommendation generated by technical confluence engines (e.g. EMA trend + RSI momentum) with predefined symbol, action, lot size, SL, and TP.
_Avoid_: Tip, bot call
